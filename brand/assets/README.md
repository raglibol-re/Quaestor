# Logos

The ring-and-fork mark. Each file is a single fixed ink (SVGs shown via `<img>` cannot inherit colour):

- `quaestor-app-icon.svg` — the mark (`#4fb39a`) on a Basalt `#121110` rounded tile. App icon, favicon, and the `icons` entry for the MCP server and its tools; works on light and dark host chrome from 16px.
- `quaestor-mark.svg` — verdigris `#1a6b59`, for Travertine (light) grounds.
- `quaestor-mark-on-dark.svg` — verdigris `#4fb39a`, for Basalt (dark) grounds.
- `quaestor-mark-ink.svg` — ink `#1c1a17`, one-colour print and light grounds.
- `quaestor-mark-reversed.svg` — ink `#ede7dc`, one-colour on dark grounds and photos.

The wordmark is set in Instrument Serif, not supplied as a file.
